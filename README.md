# Etin Labs Website

This is a simple business website starter for **Etin Labs**, focused on app creation services.

## Files

- `index.html` - main website structure
- `styles.css` - design, layout, colors, and responsive behavior
- `script.js` - mobile menu and demo form interaction

## How to open it

1. Open this folder in Visual Studio Code.
2. Open `index.html` in your browser.
3. Edit the text, sections, and contact details to match your real business.

## Easy customizations

- Change the business name and wording in `index.html`
- Update colors in `styles.css` under `:root`
- Replace placeholder project descriptions with your real work
- Connect the contact form to a backend service later if you want real submissions
